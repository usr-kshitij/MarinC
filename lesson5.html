01 / THE TWO FUNCTIONS

printf() vs scanf()

Think of them as two directions of communication.

printf()

Output

Sends information from your program to the screen.

printf ( "Hello!" );
scanf()

Input

Takes information from the user and stores it inside a variable.

scanf ( "%d" , &age );

05 / FORMAT SPECIFIERS

How does C know what type of data?

Format specifiers tell functions like printf() and scanf() what kind of value they're dealing with.

%d
Integer

Whole numbers like 10, 25, -4

%f
Float

Decimal numbers like 3.14

%c
Character

One character like A or ?

%s
String

Text such as "Hello"

06 / COMMON MISTAKES

Don't make these beginner mistakes

✗ scanf("%d", age);

For a normal variable, scanf() needs its address: &age.

✓ scanf("%d", &age);

This tells scanf where the variable is stored so it can put the value there.

✗ printf(age);

Don't treat a variable as a format string. Use a format specifier.

✓ printf("%d", age);

%d tells printf that age is an integer.
