Variables & Data Types

Computers need somewhere to store information. In C, variables give that information a name and a type.

LESSON 03
Lesson progress 12%
CHAPTER 01 • VARIABLES

Give information a name.

A variable is basically a named place where your program can keep a value. But C also needs to know what kind of value you're storing.

MARIN
Think of a variable as a labeled box. The label is its name. The value is what's inside. 📦

02 / DATA TYPES

C needs to know what you're storing

Different kinds of information need different data types. Click a card to inspect it.

int

Whole numbers without a decimal part.

float

Numbers that can contain a fractional part.

char

Character

Stores a single character.

double

Double

Floating-point type with greater precision than float.
