02 / BREAK IT DOWN

Four pieces you need to know

You don't need to understand every detail of C yet. These four concepts are enough for your first program.

01
#include

Header

Gives your program access to declarations provided by libraries.

02
main()

Entry point

Execution of a normal C program begins in the main function.

03
printf()

Output

Used to print formatted output to the standard output stream.

04
return 0;

Finish

Returns a status value from main to indicate successful completion.
