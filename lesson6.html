CHAPTER 02 • DECISION MAKING

Give your code a brain.

A program can look at a condition and decide which instructions should run. That's the foundation of intelligent program behaviour.

MARIN
Hmm... If the condition is true, I'll take one path. Otherwise, I'll take another. ✦
01 / THE IDEA

What is an if statement?

An if statement checks whether a condition is true. If it is true, C runs the code inside the block.

THINK LIKE A PROGRAMMER
"Is the student's score at least 40?"
if ( score >= 40 ) {
   printf ( "Pass" );
}

// If score is 40 or more, // "Pass" is printed.

04 / MORE THAN TWO CHOICES

else if enters the game

When you have several possible conditions, use else if.

if

First condition

Checked first. If true, its block runs.

else if

Another condition

Checked only when the earlier condition was false.

else

Everything else

Runs when none of the previous conditions were true.

CODE
MEANING
if (marks >= 90)
Check the first condition.
else if (marks >= 60)
Check this if the first condition failed.
else
Run when all previous conditions failed.
05 / COMPARISON OPERATORS

How do we compare values?

Conditions use comparison operators to produce either true or false.

==
Equal to

x == 10

!=
Not equal

x != 10

>
Greater than

x > 10

<
Less than

x < 10

>=
Greater or equal

x >= 10

<=
Less or equal

x <= 10

06 / CHECKPOINT

Final check

Read the code carefully before choosing.

QUESTION 01
What will this program print?
int age = 18;

if (age >= 18) {
   printf ( "Adult" );
}
else {
   printf ( "Minor" );
}
✦
Correct! age is 18, so age >= 18 is true.
